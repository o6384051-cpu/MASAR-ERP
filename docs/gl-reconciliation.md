# مراجعة توازن دفتر الأستاذ العام

يوفر MASAR ERP واجهة قراءة فقط لفحص توازن قيود دفتر الأستاذ العام لشركة وفترة محددتين.

## API

`masar_erp.reconciliation.get_gl_reconciliation`

المعاملات:
- `company`: اسم الشركة.
- `from_date`: تاريخ البداية بصيغة YYYY-MM-DD.
- `to_date`: تاريخ النهاية بصيغة YYYY-MM-DD.

النتيجة:
- عدد أسطر دفتر الأستاذ التي ظهرت للمستخدم وفق صلاحيات Frappe.
- إجمالي المدين وإجمالي الدائن.
- الفرق بينهما.
- `balanced`: صحيح فقط عندما يتساوى الإجماليان حسابيًا.

## ضوابط السلامة

- يتطلب تسجيل الدخول.
- يتحقق من صلاحية قراءة الشركة وGL Entry.
- يستخدم `frappe.get_list` لاحترام صلاحيات الوصول للسجلات.
- يستبعد القيود الملغاة.
- لا ينشئ أو يعدل أو يرحّل أي قيد.
- هذه مراجعة تجميعية ضمن السجلات التي يستطيع المستخدم قراءتها، وليست بديلًا عن مطابقة التقارير المالية أو مراجعة محاسب.
- يجب اختباره على موقع Frappe/ERPNext حقيقي قبل الاعتماد التشغيلي.
