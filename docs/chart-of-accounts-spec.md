# مواصفات دليل الحسابات والتوجيه المحاسبي

## الهدف والنطاق
اعتماد دليل حسابات هرمي ومرن داخل ERPNext، مع تخصيص MASAR عند الحاجة بدلاً من إنشاء دفتر أستاذ موازٍ. يجب أن يخدم شركات وفروعاً متعددة، وأن يربط العمليات التشغيلية بقيود الأستاذ العام بصورة قابلة للتدقيق.

## 1. شجرة الحسابات
- حسابات رئيسية وتجميعية وحسابات حركة فرعية بمستويات غير محدودة عملياً ضمن حدود الأداء.
- تصنيف الحسابات إلى أصول، التزامات، حقوق ملكية، إيرادات، ومصروفات، مع أنواع فرعية مثل النقدية والبنوك والعملاء والموردين والمخزون والأصول الثابتة والضرائب.
- خصائص لكل حساب: الشركة، الرمز، الاسم العربي والاسم البديل، الحساب الأب، نوع الحساب، العملة عند الحاجة، حالة التفعيل، قابلية الترحيل، والحساب المقابل/الضابط عند انطباقه.
- منع الترحيل المباشر إلى حسابات التجميع، ومنع حذف أو تغيير حساب مستخدم في قيود مرحّلة؛ يكون التعطيل أو إعادة التصنيف بضوابط وأثر تدقيقي.
- استيراد وتصدير الدليل والتحقق من تفرّد الرموز وعدم وجود دورات أو حسابات أب غير صالحة.

## 2. توجيه الحسابات الآلي
- إعداد قواعد توجيه مركزية للعمليات: المبيعات والإيرادات والمرتجعات والخصومات والمشتريات وتكلفة البضاعة والمخزون والأصول والضرائب والرواتب والأجور والتسويق والنثريات والوقود والصيانة.
- تحديد الحسابات الافتراضية حسب الشركة والفرع والمخزن ومجموعة الصنف والعميل/المورد ونوع المعاملة، مع أولوية واضحة للقواعد الأكثر تخصيصاً.
- التحقق من اكتمال التوجيه قبل اعتماد المستند أو ترحيله؛ لا يُنشأ قيد صامت أو يوجّه إلى حساب افتراضي غير معتمد.
- سجل يوضح القاعدة التي اختيرت والحسابات الناتجة، مع إمكانية المعاينة قبل الترحيل وصلاحية إدارية لتغيير الإعدادات.

## 3. الخزائن والبنوك والشيكات
- دعم عدة خزائن رئيسية وفرعية، وحسابات بنكية متعددة، وحسابات شيكات تحت التحصيل/برسم الدفع وفق السياسة المحاسبية المعتمدة.
- ربط كل خزنة/حساب بنكي بحساب الأستاذ العام، مع صلاحيات أمين الخزينة والمراجع والاعتماد.
- تقارير تفصيلية لكل خزنة أو بنك، ومجمعة لكل الخزائن أو مجموعة يحددها المستخدم، مع أرصدة افتتاحية وحركات وقبض وصرف وتحويل وتسوية.
- منع ازدواج الحسابات المرتبطة بنفس وسيلة النقدية دون قصد، وتوفير مطابقة بنكية وسجل تسويات.

## 4. العملاء والفروع والأطراف
- دعم عميل رئيسي وتحته فروع/مواقع/نقاط تعامل، مع كود مستقل لكل فرع وربط واضح بالعميل الأب.
- عرض كشف حساب ومديونية وحد ائتماني وأعمار ديون لكل فرع منفرداً، وللعميل الأب مجمعاً، مع إمكانية التصفية حسب الشركة والفرع والفترة والعملة.
- الاحتفاظ بحساب مراقبة/ذمم العملاء في الأستاذ العام، بينما تحفظ تفاصيل الطرف في دفتر الأستاذ المساعد؛ لا يُنشأ حساب أستاذ مستقل لكل عميل إلا إذا كانت سياسة الشركة تتطلب ذلك.
- تطبيق المبدأ نفسه على الموردين عند الحاجة.

## 5. التكامل مع الدورة المحاسبية
- ربط كل مستند بيع وشراء وقبض وصرف ومخزون وأصل ورواتب بحساباته المهيأة، وبمراكز التكلفة والأبعاد المحاسبية المناسبة.
- الأستاذ العام وميزان المراجعة وقائمة الدخل والميزانية والتدفقات النقدية وكشوف الأطراف يجب أن تتطابق مع القيود المرحّلة.
- دعم العملات وأسعار الصرف وفروق العملة وفق إعدادات الشركة والسياسة المحاسبية، مع حفظ سعر الصرف المستخدم في المستند.
- كل قيد مرحّل متوازن، غير مكرر، وله مصدر واضح ومستخدم وتوقيت وأثر تدقيقي؛ التصحيح عبر مستند عكسي/تسوية معتمدة لا بتعديل التاريخ المالي خفية.

## 6. التقارير
- كشف حساب هرمي مع فتح/إغلاق الفروع والحسابات.
- دفتر الأستاذ، ميزان مراجعة إجمالي وتفصيلي، تحليل أرصدة حسب الشركة والفرع ومركز التكلفة والعملة.
- تقارير الخزائن والبنوك والشيكات، وتقارير العملاء على مستوى الفرع والعميل الأب، وأعمار الديون والمطابقة.
- إظهار مصدر الرصيد وتاريخ آخر تحديث، مع تصدير مضبوط الصلاحيات.

## 7. المعايير المصرية وIFRS
- تصميم قابل للتهيئة لسياسات الشركة ودليل حسابات قابل للمواءمة مع معايير المحاسبة المصرية (EAS) ومعايير IFRS ذات الصلة.
- إعداد مصفوفة ربط بين الحسابات وبنود التقارير والإفصاحات، وتوثيق السياسات المحاسبية والاختلافات عند وجودها.
- لا يُعلن الامتثال لمعيار أو قانون لمجرد وجود تصنيف حسابات؛ يلزم مراجعة محاسب قانوني مختص، والتحقق من الإصدار الساري، واختبارات تقارير وإفصاحات فعلية.

## 8. الأمن والحوكمة
- صلاحيات منفصلة لإنشاء الحساب وتعديله واعتماده وإدارة التوجيهات وعرض الأرصدة وتصدير التقارير.
- تقييد الوصول حسب الشركة والفرع ومركز التكلفة والحساب، مع فصل المهام وتسجيل كل تعديل.
- لا يسمح بتغيير إعدادات التوجيه أو الحسابات الحساسة بعد بدء الاستخدام دون موافقة وسجل تغيير وخطة أثر.
- حماية التقارير المالية والمرفقات ومنع تسريبها عبر التخزين المؤقت العام.

## 9. اختبارات القبول
1. إنشاء شجرة متعددة المستويات ومنع الترحيل إلى حساب تجميعي.
2. إنشاء خزائن وبنوك متعددة وربط كل منها بحساب أستاذ صحيح.
3. استخراج تقارير خزنة منفردة ومجموعة خزائن والإجمالي ومطابقتها مع الأستاذ.
4. إنشاء عميل أب وفروع، والتحقق من كشف كل فرع والإجمالي دون تكرار.
5. اختبار قواعد التوجيه لكل نوع معاملة وحالات نقص/تعارض الإعدادات.
6. إثبات توازن القيود وعدم تكرارها وصحة العكس والتسوية.
7. مطابقة دفتر الأستاذ وميزان المراجعة والتقارير المالية.
8. اختبارات عزل الشركات والصلاحيات وسجل التدقيق.
9. اعتماد مراجعة محاسبية مصرية موثقة قبل أي ادعاء امتثال EAS/IFRS.

## قرار التنفيذ
ERPNext هو مصدر الحقيقة لدليل الحسابات والقيود والأستاذ العام. يقتصر تطبيق MASAR على التهيئة والواجهات والتقارير وقواعد التوجيه الإضافية التي لا يوفرها الأساس، مع تجنب تكرار الوظائف أو إنشاء دفتر موازٍ.
